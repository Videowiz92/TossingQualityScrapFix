# Changelog

## 1.0.0
- Initial release, written against ZetArtifacts 1.6.6 and Quality (ItemQualities) 0.8.5.
- Scrapping a Quality item with the Artifact of Tossing now drops the Quality scrap of the same tier (Uncommon / Rare / Epic / Legendary)
  instead of vanilla scrap. Works for white, green, red and boss items.
- Config `FixQualityScrap` (default on) in `BepInEx/config/com.videowiz92.tossingqualityscrapfix.cfg`.
